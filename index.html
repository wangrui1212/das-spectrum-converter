计算公式与约定

Δf = fs / N

BENBW = fs · Σw² / (Σw)²

PSD = ARMS² / BENBW,   ASD = √PSD,   APeak = √2 · ARMS

Kφ→pε = λ / (4πnGξ) · 10¹²

以线性相位 PSD（rad²/Hz）作为内部中间量。PSD 的物理量转换使用 K²；幅度与 ASD 使用 K。
