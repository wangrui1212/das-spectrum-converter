# DAS Spectrum Converter

An offline-capable, single-file DAS spectrum conversion tool. It supports Peak, RMS, PSD and ASD conversion between phase (rad) and strain (pε), with Linear/dB display modes.

The GitHub Pages deployment uses the industrial-browser-compatible build, including Microsoft Edge 92.
